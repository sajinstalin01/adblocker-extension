Filter updates

The extension checks the project's versioned JSON rules on GitHub daily. Bundled rules remain active if the network is unavailable. Only validated block rules are accepted; remote code is never downloaded or executed.

Community JSON filter lists

Subscribe to trusted HTTPS JSON rule files only. Each list must be an array of block rules in Chrome Declarative Net Request JSON format (up to 500 rules per list). Standard EasyList/Adblock Plus text lists are not parsed directly. Only add sources you trust.
